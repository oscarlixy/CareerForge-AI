📋 准备工作（5分钟）
════════════════════════════════════════════════════════════════

1️⃣  注册 Hugging Face 账号
   访问：https://huggingface.co/join
   填写邮箱、用户名、密码 → 验证邮箱 → 完成

2️⃣  注册 DeepSeek 账号并获取 API Key
   访问：https://platform.deepseek.com
   注册登录 → API Keys → 创建新密钥 → 复制保存
   记得充值 ¥10-20

3️⃣  获取 Hugging Face Access Token
   访问：https://huggingface.co/settings/tokens
   New token → 选择 write 权限 → Generate → 复制保存


🚀 方法一：一键部署（最简单！）
════════════════════════════════════════════════════════════════

步骤 1：先在 HF 创建 Space
   访问：https://huggingface.co/new-space
   SDK 选择：Docker ⚠️（必须）
   点击：Create Space

步骤 2：运行一键脚本
   打开终端，进入本文件夹：
   cd /path/to/CareerForge-完整代码包
   
   运行脚本：
   ./一键部署.sh
   
   按提示输入：
   • HF 用户名
   • Space 名称
   • HF Token（推送时）

步骤 3：配置 API Key
   访问：https://huggingface.co/spaces/你的用户名/space名/settings
   
   Secrets → New secret → 填写：
   Name:  DEEPSEEK_API_KEY
   Value: sk-你的密钥
   
   点击 Add

步骤 4：等待构建（3-5分钟）
   在 App 标签查看进度

步骤 5：开始使用！🎉


🌐 方法二：网页上传（无需命令行）
════════════════════════════════════════════════════════════════

步骤 1：创建 Space
   https://huggingface.co/new-space
   SDK: Docker → Create

步骤 2：上传文件
   Files → Add file → Upload files
   依次上传：
   • README.md
   • app.py
   • requirements.txt
   • Dockerfile
   → Commit changes

步骤 3：上传 static/index.html
   Add file → Create a new file
   文件名：static/index.html
   粘贴代码 → Commit

步骤 4：配置 API Key
   Settings → Secrets → New secret
   Name: DEEPSEEK_API_KEY
   Value: sk-xxxxx

步骤 5：等待 & 使用
