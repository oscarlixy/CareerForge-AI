## ✨ 功能特点

### 🎯 1. Smart Resume（智能简历优化）
根据职位描述，AI 自动生成优化的简历和匹配度分析

### 💼 2. Interview Coach（AI 面试教练）
生成针对特定职位的面试问题、考察点和回答策略

### 📚 3. Learning Path（学习路径规划）
根据当前技能和目标职位，AI 规划个性化学习路径

### ✉️ 4. Cover Letter（求职信生成）
AI 撰写专业、个性化的求职信

### 💼 5. LinkedIn Optimizer（领英优化）
优化您的 LinkedIn 标题、简介和个人品牌

### 💰 6. Salary Intelligence（薪资分析）
分析市场薪资并提供谈判策略

## 🚀 使用方法

### 第一步：打开应用
点击上方的「App」标签即可使用

### 第二步：选择功能
选择您需要的功能标签（简历、面试、学习路径等）

### 第三步：填写信息
根据提示填写相关信息（越详细越好）

### 第四步：生成内容
点击生成按钮，等待 AI 为您创建内容（通常需要 10-30 秒）

### 第五步：使用结果
- 复制生成的内容
- 导出为 PDF（简历功能）
- 根据建议进行优化

## 🎓 最佳实践

1. **提供详细信息** - 输入越详细，生成质量越高
